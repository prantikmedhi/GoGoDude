# gogodude

A small 2D platformer made with Godot. Jump across platforms, collect coins, and watch out for slimes. You can defeat them by landing on top of them. Fall off or get hit, and the level starts over.

[Play on itch.io](https://prantikmedhi.itch.io/gogodude)

## Controls

- Left / Right arrows to move
- Space to jump

To run it locally, import `project.godot` in Godot 4.7 and press `F5`.
